How can I edit this according to what font and also colors I want to integrate and also how to link this with sheets for order history and record and with that the payment gateway

27 Mar

Great questions! Let me break it down for you across all three areas.

Fonts The app currently uses Satisfy (the logo script), Playfair Display (headings), and DM Sans (body text) — all from Google Fonts. To change any of them, you just need to do two things: swap the font name in the @import link at the top, and update the font-family references in the CSS. Google Fonts (fonts.google.com) is the easiest place to browse and pick — just copy the import link they give you.

Colors All the colors are stored as CSS variables at the very top of the <style> block, under :root { }. You'll see names like --clay, --earth, --turmeric, --leaf etc. Changing any value there updates it everywhere in the app instantly. For example if you want a different primary accent color, just change --clay to whatever hex code you like. Tools like coolors.co are great for building a palette.

Google Sheets (Order Records) The cleanest free way to do this is with Google Apps Script. Here's the flow: you create a Google Sheet, then go to Extensions → Apps Script and write a small doPost() function that receives your order data and appends a row. You deploy it as a Web App and get a URL. In the HTML app, when someone places an order, you send the data to that URL with a fetch() call. Each order then auto-logs as a new row with name, phone, plan, bowls, total, payment method, address, timestamp — everything. No paid backend needed.

Payment Gateway You have two practical options depending on your scale. Razorpay is the most popular for Indian businesses — it supports UPI, cards, netbanking, and has a simple JavaScript SDK you drop into the page. You create an order on their dashboard or via API, load their checkout popup, and on success you get a payment ID you can log to your sheet. PhonePe for Business and Cashfree are solid alternatives with similar flows. All of them charge around 2% per transaction for UPI. The basic integration is about 15–20 lines of JS.
